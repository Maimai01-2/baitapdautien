# Bài tập lập trình đầu tiên
## 1. Mô tả bài toán 
 - **Đề bài:** Viết chương trình nhập vào hai số nguyên từ bàn phím và tính tổng của chúng.
 - **Đầu vào (Input):** Hai số nguyên a và b
 - **Đầu ra (Output):** Giá trị tổng a + b
 - **Ngôn ngữ lập trình:** Python 3.
## 2. Cách chạy chương trình
1. Cài đặt **Python 3** trên máy tính
2. Tải tệp main.py về máy tính và mở Terminal:
3. Chạy lệnh:
```bash
python main.py
```
4. Nhập lần lượt 2 số nguyên từ bàn phím và nhấn **Enter** để xem kết quả.
